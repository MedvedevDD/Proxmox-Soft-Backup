

## Восстановление конфигурации Telegraf

Safe Recovery поддерживает цель `telegraf/configuration`. Операция выполняется в следующем порядке:

1. Проверяется целостность исходного пакета PSB.
2. Создаётся и проверяется rollback-пакет текущего каталога `/etc/telegraf`.
3. Служба `telegraf.service` останавливается только в том случае, если она была активна до восстановления.
4. Каталог `/etc/telegraf` восстанавливается из выбранного компонента резервной копии.
5. Проверяется контрольная подпись восстановленного каталога.
6. Telegraf запускается снова только в том случае, если служба была активна до восстановления.
7. При ошибке автоматически возвращается предыдущая конфигурация.

Команда выполнения намеренно восстанавливает только один компонент за один запуск.
